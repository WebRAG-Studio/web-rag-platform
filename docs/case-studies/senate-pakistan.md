# Case study: parliamentary information assistant

An early internal deployment explored source-grounded search across a public parliamentary website and a large document archive. It demonstrated why exact document lookup, page-level citations, OCR confidence, current-versus-historical metadata, and conservative fallbacks matter.

Sanitized aggregate outcomes included a bilingual English/Urdu interface, page-level citations, optional voice interactions, a large local searchable index, and extensive automated acceptance checks.

This repository contains no copied parliamentary dataset, downloaded PDFs, private indexes, credentials, or institution-specific runtime rules. The case study is architectural context, not an endorsement or an official deployment.
